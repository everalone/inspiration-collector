# v2.5.0 · 组件规范统一与失败记录管理

本版本将已验收的本地 v0.2.4.2–v0.2.4.4 改动合并公开发布，沿用既有文章、卡片、原图和设置。

## 界面与交互

- 按确认后的组件规格统一按钮用途与尺寸档位、输入框、分类标签、文章卡、配色卡、分类统计卡、弹窗、画廊和窗口控件。
- 分类标签保留红、绿、蓝、紫等语义色，选中边框与对应分类一致；输入框增加校验错误和提交等待状态。
- 右侧分类卡保持180×98，从左到右排列，水平8px、换行17px固定间距；只有两张卡时也不再分散到两端。980px默认窗口支持三列加两列。
- 配色编辑先展示颜色及添加操作，再展示说明；保留窄窗口滚动与保存入口。
- 字体优先使用本机Noto Sans SC，缺少时回退微软雅黑/Segoe UI，不下载字体。

## 失败记录管理

- 每条本地失败任务下方新增「删除记录」，手动任务同时保留「重试」。删除期间显示等待状态，避免重复提交；请求失败保留记录并提示原因。
- 删除同时隐藏同链接、同操作下被折叠的较早失败尝试，更新失败计数，刷新和重启后不重新出现。
- 文章、卡片、原图和处理回执保留。对应手机失败轮次从本机失败列表隐藏，云端记录不被删除；同一尝试的ACK恢复复用原结果，新一轮仍正常显示。

## 安装与升级

- Windows x64：`InspirationCollector-Setup-2.5.0.exe` 安装版、`InspirationCollector-Portable-2.5.0.exe` 便携版。
- v0.2.4.1及之后版本可从标题栏更新入口检查、下载并重启更新；升级保留原数据目录。早期版本也可直接下载新安装包。
- `update.json`提供版本、下载地址、大小和SHA-256；`latest.yml`随安装包一并发布。安装包未做代码签名。
- 本次只更新桌面端，无需更新云端收件箱或重新绑定ClawBot。新安装仍需自行配置模型和可选手机收集服务。

## 验证与实现文档

- 类型检查、212项隔离回归、核心构建；发布流水线检查包内隐私边界、SQLite/sharp/HTTP运行时和实际Portable双启动后的延迟图片加载。
- 本轮界面已在1440/980窗口进行隔离几何与交互核对；此前本机安装验收保留30篇文章、482张卡片及配置。其他Windows缩放与字体回退、真实手机通知不由这些检查替代。
- [组件设计规格说明书](https://github.com/everalone/inspiration-collector/blob/v2.5.0/component-spec.md)记录尺寸、颜色、间距、交互状态及尚未确认的边界；Figma分类卡靠左及失败删除按钮尚待回写。
