# v2.6.0 · 三套可选主题与流体布局

新增暖纸编辑、液态玻璃、冷灰专业三套界面主题，明暗跟随系统，并重排顶栏、列表与详情布局。

- 设置 → 外观可切换三套主题与「跟随系统 / 浅色 / 深色」；选择保存在本机，不写入用户数据库。
- 暖纸编辑为默认主题：米纸底、衬线标题、目录式文章列表与纸纹。
- 液态玻璃：窗口内极光底、悬浮玻璃面板与有色玻璃分类卡；模糊只用于面板层，列表卡片使用伪玻璃控制滚动性能。
- 冷灰专业：中性灰阶、单一靛蓝强调、最高信息密度。
- 顶栏从 208px 收到约 146px，收集与搜索并成一行；文章卡取消 328×156 固定尺寸，分类统计改为自适应栅格；详情正文 860px 居中。
- 主操作、界面操作与内容操作按角色分层；分类标签改为分类色点 + 激活态；更新按钮与浮层按三套主题分别设计。
- 动效统一 150–350ms：视图淡入上浮、列表错峰入场、画廊拖动跟手，全部尊重「减少动态效果」设置。
- 沿用现有数据目录，不迁移或清空文章、卡片、设置、任务记录及原图。

验证：类型检查、核心构建与 212 项回归通过；隔离 Electron 覆盖 3 主题 × 明暗 × 1440/980，检查布局不变量、无横向溢出、主题切换与更新按钮状态差异。Windows 透明窗口、系统缩放与缺少 Noto Serif SC 时的字体回退需在目标机器上人工验收。

下载：Windows x64 Setup 或 Portable；现有支持应用内更新的版本可在标题栏检查更新。发布同时提供 `latest.yml` 和 `update.json`，用于版本检测及下载校验。
