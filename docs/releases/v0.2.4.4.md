# v0.2.4.4 · 本地失败任务记录删除

> 历史本地阶段，未单独公开发布；功能已汇入 [v2.5.0](v2.5.0.md)。

每条本地失败任务下方新增右对齐的「删除记录」按钮，使用32px高、8px圆角的S档危险操作样式；手动任务的「重试」放在同一操作行。请求期间禁用按钮，失败时保留记录并提示原因。

删除只归档任务显示记录：同一链接、同一操作下被折叠的较早失败尝试一起隐藏，刷新或重启后不再重新出现，失败计数随之更新。相应手机失败轮次也从本机收件箱失败列表隐藏；云端记录和处理回执保留，ACK重放不会再次解析。新一轮处理结果仍正常显示，文章、卡片、原图及配置不受影响。

类型检查、核心构建、212项回归测试、隔离Electron按钮位置/点击/计数检查通过；包边界1178项与打包SQLite/sharp/HTTP运行时通过。本机覆盖安装并确认按钮出现，原30篇文章、482张卡片及配置、任务记录保留；未操作用户的真实删除按钮。本轮未复测真实Portable双启动或手机端通知。

仅本地构建与安装，未发布GitHub。
