# v0.2.4.1 · 应用内更新、文章浏览与便携版修复

本版汇总 v0.2.2 以来的改进：应用内更新、任务记录归档、统一标题栏、文章总览与新配色，并修复便携版重复启动后链接无法导入的问题。v0.2.3 和 v0.2.4 为本地开发阶段，未独立公开发布，其功能均包含在本版。

## 应用内更新与统一标题栏

- 标题、设置、任务、文章统计和窗口按钮整合为一行，采用圆角与淡色磨砂效果。空白区域可拖动、双击最大化或还原；关闭窗口继续驻留托盘。
- 更新按钮位于最小化按钮左侧。程序启动约 10 秒后、运行期间每 6 小时检查新版本，也可手动检查。
- 发现更新后点击「下载更新」，校验完成后点击「重启更新」。下载期间可以继续使用；还有收集任务或手机回执待确认时，保留下载结果，等待空闲后安装。
- 下载只使用本项目固定的 GitHub 发布源，校验版本、文件大小与 SHA-256，不传送文章、设置或密钥。更新后继续使用原数据目录。

## 更清楚的任务记录

- 对应文章后来成功导入时，先前失败退出当前列表与失败计数，同一项未解决失败只保留当前提示。
- 默认显示最近 10 条完成记录。「清空已完成记录」只归档记录，保留文章、卡片、图片和手机回执恢复所需结果。
- 任务按钮显示处理中、已完成或失败，并始终可以打开任务记录。同一链接已排队或处理中时禁止重复提交。
- 手机任务继续按每轮最多 3 次文章处理尝试执行；全部失败后停止自动重试，手动重新排队才开启新一轮。

## 文章优先的浏览方式

「全部」默认只显示文章父卡片，包含标题、作者、卡片数量、分类与摘要。选中文章后，右侧显示文章总览：标题、作者、导入时间、圆角分类数量卡和原文画廊。

- 点击顶部分类：先选择文章，再进入这篇文章对应的子卡片。
- 点击文章总览中的分类卡：直接进入本篇对应子卡片，并清除旧搜索条件。
- 「返回文章」保留当前分类；「文章总览」返回本篇概览。后台刷新保留当前浏览范围，快速切换不会被旧请求覆盖。

主题采用奶油黄与天空蓝（`#F7F1C8`、`#6FAEE0`、`#C6E4F5`、`#8CC9EC`），各分类保留独立的彩色标识，顶部标签、卡片徽标与分类数量卡同类同色。卡片悬停轻微上浮，按钮按下缩至 97%。

原图支持按钮、左右方向键和横向拖动，使用扇形倾斜的滑入滑出效果，并适配系统的减少动态效果设置。分类栏下的 3px 进度条跟随右侧详情阅读位置。

## 便携版重复启动修复

同一份旧 Portable 尚在运行时再次启动，第二个实例退出曾误清理首实例仍需要的临时文件，造成窗口仍可显示、后续导入却提示 sharp 组件缺失。本版每次启动使用独立解压目录，正常使用继续共享原灵感库和单实例锁。

新增真实 Portable 重复启动检查：第二个实例退出后，确认首进程与依赖文件完整，再首次执行图片裁剪。此检查加入发布流水线。

需要对比旧版的开发者可使用项目中的 `launch-old-version.cmd`，选择版本后创建独立临时目录、端口及空白测试库。入口支持现有 v0.2.0 起的隔离构建，更早的硬编码版本会跳过；需保留对应 Portable、`win-unpacked`，并安装 Node.js 和项目依赖。测试库默认无 Key、关闭手机收件箱，退出后保留。

## 下载与升级

Windows x64 提供以下文件：

- [InspirationCollector-Portable-0.2.4.1.exe](https://github.com/everalone/inspiration-collector/releases/download/v0.2.4.1/InspirationCollector-Portable-0.2.4.1.exe)：单文件便携版。
- [InspirationCollector-Setup-0.2.4.1.exe](https://github.com/everalone/inspiration-collector/releases/download/v0.2.4.1/InspirationCollector-Setup-0.2.4.1.exe)：安装版。
- `latest.yml` 与 `update.json`：版本与下载校验信息。

**从 v0.2.2、本地 v0.2.3 / v0.2.4 升级，需手动换包一次。** v0.2.2 没有更新器；v0.2.3 / v0.2.4 的更新器仅接受三段版本。v0.2.4.1 起支持三段和四段补丁版本。

1. 从托盘菜单退出旧程序，备份 `%AppData%\灵感收集\` 下的 `data/` 和 `assets/`。
2. 安装新版 Setup 或启动新版 Portable，继续使用原文章、卡片、图片和配置。
3. 打开任务与设置确认状态。已有 v0.2.2 收件箱、ClawBot 与快捷指令无需改动服务器或重新绑定。

新安装默认没有 API Key、收件箱地址或 Token，需自行配置模型服务；不会使用作者的服务器或模型账户。
