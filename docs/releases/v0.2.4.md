# v0.2.4 · 文章总览与阅读体验

**历史记录：v0.2.4 为本地开发与验收阶段，未独立公开发布。** 本页保留该阶段的文章浏览与视觉改动记录；全部功能已并入 [v0.2.4.1](v0.2.4.1.md)，下载和当前升级方式以新版说明为准。

## 先看文章，再进入灵感卡片

「全部」默认只显示文章父卡片：标题、作者、子卡片总数、分类数量和摘要。点选文章后，右侧展示文章标题、作者、导入时间、24px 圆角的分类数量卡，以及原文图片画廊。

- 点击顶部分类标签：先列出包含该类卡片的文章，再点文章进入它的对应子卡片。
- 点击右侧文章分类卡：直接进入该文章对应子卡片，并清除旧搜索，避免新入口被旧搜索词遮蔽。
- 左侧「返回文章」回到当前分类的文章列表；右侧「文章总览」返回该文章概览。后台刷新会保留文章总览，不自动跳回第一张子卡片。
- 作者与数量基于完整文章统计，搜索或局部筛选不会把文章总数误写为当前匹配数。快速切换时忽略旧请求；删除文章后自动退出已经失效的范围。

## 色彩与交互

主题使用 `#F7F1C8`、`#6FAEE0`、`#C6E4F5`、`#8CC9EC`，搭配适合阅读的浅色背景和深色正文。左侧列表与顶部标签区域底色按最终设计交换；分类保留旧版彩色标识，顶部分类标签、子卡片徽标和文章分类卡使用同一套分类色，五类文字/底色对比度均达到 4.5:1。

父卡片、子卡片和分类数量卡悬停时轻微上浮并增加阴影。按钮按下缩至 97%，松开恢复。原文画廊支持按钮、左右方向键和横向拖动切换，滑入滑出伴随扇形倾斜；系统开启减少动态效果时使用简化切换。

分类栏下新增 3px 阅读进度条，随右侧详情滚动增长，切换文章或卡片时重置。图片加载失败显示提示，旧图片回调不会污染新文章。

## 任务反馈

任务按钮显示 Spinner 与处理中、勾选与已完成、或失败状态；处理中仍能打开任务记录。同一链接排队或处理中时，收集按钮禁用，防止重复提交。

重试次数与归档规则保持原有含义：手机任务每轮最多 3 次文章处理（首次加 2 次重试）；最终失败后停止，手动重新排队才开启新一轮。任务默认显示最近 10 条完成记录，清空记录不删除文章和卡片。

## 升级与验证

Windows x64 产物为 Setup、Portable、`latest.yml`、`update.json`。继续使用 `%AppData%\灵感收集\`，无需迁移数据或重新配置服务器、ClawBot 和快捷指令。

v0.2.2 没有更新器，首次升级仍需手动安装或运行新版 Portable。已有 v0.2.3 可在本版正式发布后通过应用内更新获取；本地构建不等于已公开发布。

本轮 **201 项回归全部通过**，类型检查、核心构建、1176 项包内容边界检查与空配置打包运行时验证通过。虚构文章和隔离数据库覆盖导航、阅读进度、任务反馈、请求竞态与重复提交；原生桌面检查了文章总览、两条分类路径、画廊和阅读进度。测试未调用真实模型。本机 Portable 切换后文章、卡片和设置保全；本版未进行 NSIS 覆盖安装或公开 GitHub CI 验收。
