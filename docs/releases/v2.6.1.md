# v2.6.1 · 玻璃质感与原图裁剪修复

修复 v2.6.0 反馈的四项问题，沿用已有文章、配置与主题设置。

- 液态玻璃的「收集」按钮改为半透明蓝色玻璃，去掉实心渐变与厚重投影。
- 分类统计卡增加高光、斜向反射与彩色透明底，能透出窗口底色。
- 分类卡的箭头改到右侧垂直居中，不再被裁切；标签与数字垂直居中。
- 左侧吸顶的浏览标题加实底与模糊，滚动时不再与卡片文字混叠。
- 卡片详情里的来源裁剪图改为居中显示。
- 裁剪定位更准：按图片 EXIF 方向校正后再裁切，四边增加约 1.5% 余量；提取提示词要求完整框住文字块并留边，同时修正多批次时的图片来源编号。
- 沿用现有数据目录，不迁移或清空文章、卡片、设置、任务记录及原图。

注意：已有文章的定位框不会自动重算；需要改善旧卡片的裁剪时，对该文章执行「重跑」。

验证：类型检查、核心构建与 216 项回归通过；隔离 Electron 复核三套主题 × 明暗 × 1440/980，并检查玻璃材质、吸顶栏、图片居中和分类卡箭头。EXIF 旋转的合成图验证了裁剪方向。

下载：Windows x64 Setup 或 Portable；支持应用内更新的版本可在标题栏检查更新。发布同时提供 `latest.yml` 和 `update.json`。
