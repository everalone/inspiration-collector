# v0.2.1 · ClawBot 收集与文章标题回执

微信公众号文本链接可通过独立 ClawBot 桥接加入个人收件箱。机器人在入队后回复一次，在电脑完成导入并确认后再发送完成通知；完成通知优先使用桌面解析得到的文章标题。

- 桥接只接收扫码绑定者的公众号纯文本链接，支持多个链接、去重、持久队列与重启恢复；不运行完整 OpenClaw Agent，不执行聊天指令。
- 桌面成功回执持久保存并发送文章标题；服务器 `/status` 提供鉴权只读查询，旧成功记录可补填缺失标题。失败通知与成功通知分开，补发通知不会重新提交分析。
- 收件箱兼容公众号长链接，并修复畸形请求导致进程退出的问题。

桌面和服务器需要配套更新。入队时标题仍是尽力读取，旧客户端或旧记录缺失标题时使用无标题回复。公众号文章卡片直接转发尚不在接收范围。

验证：96 项隔离回归测试、TypeScript 核心构建、包内容边界检查及空数据目录下的打包运行时检查通过。本页保留 v0.2.1 的功能记录；这些改动随 [v0.2.2](https://github.com/everalone/inspiration-collector/releases/tag/v0.2.2) 一并公开发布。
