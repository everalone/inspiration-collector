# v0.2.3 · 应用内更新、任务状态修复与统一标题栏

**历史记录：v0.2.3 为本地开发与验收阶段，未独立公开发布。** 本页保留该阶段的改动与验证记录；全部功能已并入 [v0.2.4.1](v0.2.4.1.md)，下载和当前升级方式以新版说明为准。

## 应用内检查与安装更新

- Windows x64 安装版和便携版在启动约 10 秒后检查新版本，运行期间每 6 小时再检查一次；也可点击标题栏中最小化按钮左侧的更新按钮手动检查。
- 发现新版本后点击「下载更新」，下载并校验完成后点击「重启更新」，应用会退出、安装并重新启动。下载期间可以继续浏览和收集。
- 还有排队或处理中的任务、正在同步手机收件箱，或手机回执等待确认时，暂不安装，并保留已下载的更新供稍后重试。
- Setup 和 Portable 均沿用 `%AppData%\灵感收集\`，保留文章、卡片、原图和配置。网络、校验或安装准备失败时显示原因，当前版本可继续使用。
- 更新只访问本项目固定的 GitHub 发布源及其下载服务，不传送私有配置或文章数据。源码开发态和普通浏览器不执行应用内安装。

## 已恢复的任务不再显示为失败

对应收集或重跑后来成功时，先前失败记录会从当前任务列表和失败计数中移除，旧记录中的恢复关系也会自动整理。同一项未解决失败只保留当前需要处理的提示。

任务列表默认显示最近 10 条已完成任务。「清空已完成记录」只归档任务记录，不删除文章、卡片或图片；用于恢复手机回执的处理结果仍然保留，避免清空显示记录后重复分析。仍未解决的失败继续可见，可查看报告并按原流程重试。

## 一行标题栏

品牌、设置、任务、文章统计、更新与窗口按钮合并到同一行，采用圆角和淡色磨砂效果。空白区域可拖动窗口、双击最大化或还原；最小化、最大化/还原和关闭按钮集中在右侧。关闭窗口继续驻留托盘，托盘菜单的「退出」才会结束程序。

## 升级方式

**v0.2.2 本身没有更新器，需要首次手动升级一次。** v0.2.3 发布后，在托盘退出旧程序，备份 `%AppData%\灵感收集\` 中的 `data/` 和 `assets/`，再安装新版 Setup 或启动新版 Portable。数据目录保持不变，此后的版本可通过应用内更新。

已有 v0.2.2 云端收件箱与 ClawBot **无需更新服务器**；快捷指令地址、Token 和绑定方式保持不变。从 v0.2.1 或更早版本升级、且云端尚未配套升级的用户，仍需完成 [v0.2.2 的服务器升级步骤](v0.2.2.md#从旧版本升级)。

## 发布文件与验证

发布流水线将执行回归测试、类型检查、打包、包内容边界和打包运行时检查，然后上传 4 个文件：

- `InspirationCollector-Setup-0.2.3.exe`
- `InspirationCollector-Portable-0.2.3.exe`
- `latest.yml`
- `update.json`：记录安装包版本、下载地址、大小和 SHA-256，供应用检查更新并校验下载内容。

本地 182 项回归通过，覆盖更新状态与窗口接口、任务恢复与归档、安装前任务保护及更新清单。Portable 已完成隔离环境中的真实替换与重启验收；Setup 已构建，尚未进行 NSIS 覆盖安装实测。v0.2.3 的 GitHub 发布流水线尚未触发；正式发布后的结果见 [GitHub Actions](https://github.com/everalone/inspiration-collector/actions/workflows/release.yml)。
